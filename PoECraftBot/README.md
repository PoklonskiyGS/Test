# PoE Craft Bot v3.0

Бот автоматического крафта для **Path of Exile** (Windows).
Функционал v3.0 ориентирован на бесплатный (Basic) уровень
[Path of Craft](https://pathofcraft.net/crafter1/) — множественные валюты,
крафт по весу, паузы и human-like поведение.

> ⚠️ **Дисклеймер.** Использование любых авто-инструментов нарушает
> ToS Grinding Gear Games и может привести к бану аккаунта.
> Пользуетесь на свой страх и риск (в том числе при стримах).

### Как бот «думает» (magic-предмет)

```
читаем предмет (Ctrl+C или OCR)
 ├─ corrupção / не идентифицирован → стоп
 ├─ цель достигнута (все моды ИЛИ суммарный вес ≥ порога)
 │    ├─ Chance включён и задан паттерн → рероллим цвета соккетов (до N попыток)
 │    ├─ Alchemy в финале → применяем Alchemy Orb
 │    │    └─ Eldritch включён → фаза Rare: рероллим Eldritch до цели
 │    └─ стоп: УСПЕХ
 └─ цель не достигнута:
      ├─ Vaal: есть «исключённый» мод → Vaal Orb (снимаем)
      ├─ Essence: качество ≥ нужного и ≤1 мода → Essence (лимит капаний)
      ├─ 0–1 мод  → Augmentation (добавить) — иначе Chaos/Deck/Alteration
      └─ 2 мода   → Stacked Deck (по вероятности) → Chaos → Alteration
```

### Крафт по весу

В таблице «Целевые моды» у каждого мода есть **вес**. Если задать
**Суммарный вес** > 0, крафт останавливается, когда сумма весов найденных
модов достигла порога (не обязательно все моды). Порог 0 — классический
режим: нужны все целевые моды.

Пример: `Movement Speed (вес 2)`, `to maximum Life (вес 1)`,
`increased Damage (вес 1)`, суммарный вес = 3 → стоп, когда найдена
Movement Speed + любой из остальных двух.

### Пауза по лимиту валюты

«Лимит валюты (пауза)» = N — бот останавливается после N применений любой
валюты (весь прогон, не по каждой валюте отдельно). Лимит 0 — выключен.
Счётчик сбрасывается при каждом запуске.

## Установка

1. Windows 10/11, Python 3.9+
2. `pip install -r requirements.txt`
3. (опционально, для OCR без Ctrl+C) Tesseract:
   https://github.com/UB-Mannheim/tesseract/wiki — путь ищется автоматически
4. Запуск: `run.bat` (или `python bot_launcher.py`)

## Быстрый старт

1. **Вкладка «Предмет и моды»**
   - выберите тип предмета (implicit-счётчик подставится автоматически
     кнопкой «📥 Загрузить настройки предмета»);
   - добавьте целевые моды: в таблицу вручную (мод / мин. значение / вес)
     или из базы через «Быстрое добавление»;
   - при желании задайте «Суммарный вес»;
   - для Vaal Orb добавьте «Исключённые моды» (подстроки, которые бот снимает).
2. **Вкладка «Методы крафта»** — отметьте валюты, которыми бот вправе
   пользоваться. Для Chance укажите паттерн соккетов; для Deck — вероятность;
   для Essence — нужное качество.
3. **Вкладка «Позиции»** — в игре наведите курсор на предмет и валюты и
   нажмите `Ctrl+1…Ctrl+0` (или «Задать»). Позиции нужны только для
   включённых методов + предмет.
4. **Вкладка «Настройки»** — задержки, максимум попыток, лимит валюты, OCR.
5. `F8` — старт/пауза, `F9` — аварийный выход. Лог виден в окне GUI.

## Файлы

| Файл | Назначение |
|---|---|
| `bot_launcher.py` | точка входа (GUI) |
| `poe_craft_gui.py` | GUI (вкладки: предмет/моды, методы, позиции, настройки, хоткеи) |
| `craft_engine.py` | чистая логика: парсинг предмета, весы, решения |
| `crafting_bot.py` | основной цикл крафта |
| `actions.py` | мышиные действия (ПКМ валюта → ЛКМ предмет) |
| `item_reader.py` / `ocr_reader.py` | чтение предмета: Ctrl+C / OCR (Tesseract) |
| `config_gui.py` | схема конфига v2 + миграция со старых конфигов |
| `bot_config.json` | ваш конфиг (автосохраняется) |
| `test_engine.py` | тесты логики движка (17) — `python test_engine.py` |
| `test_bot_sim.py` | симуляция цикла бота без игры (7 сценариев) — `python test_bot_sim.py` |

Старые конфиги v1 (`target_mods` / `target_mods_with_values`) при загрузке
автоматически мигрируются в v2.
